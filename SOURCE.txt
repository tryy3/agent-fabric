Agent Fabric source code
========================

The corresponding source for Agent Fabric is published at:

https://github.com/tryy3/agent-fabric

Published container images carry an org.opencontainers.image.revision label
whose value is the exact Git commit used for the build. Check out that commit
to obtain the source corresponding to a particular image digest.
