# Report format

The final report is one Markdown file, `research/<slug>/report.md`.

```
# <Title that states the question>

> Researched <date> from <n> sources. Depth: <quick|normal|deep>.

## Summary

Two to five sentences that answer the question directly, with the main caveat.

## <Section per sub-question>

Evidence in short paragraphs. Every factual claim ends with a citation like [3].
Use a table when you compare options on the same attributes.

## What is uncertain or missing

Disagreements between sources, claims with only one source, things you could not find.

## Conclusion

What to take away, and what you would check next.

## Sources

1. <Title> - <URL>
2. ...
```

## Citation style

- Use `[n]` where n is the number in `sources.md` and in the Sources list. Keep the same numbers in both files.
- Put the citation at the end of the sentence it supports, before the full stop is fine: `... was released in 2025 [4].`
- A claim backed by two sources gets both: `[2][5]`.
- Quote at most one short phrase per source, in quotation marks. Otherwise paraphrase.
- Do not cite a source for something it does not say. If you are inferring, write "this suggests".

## Length

Aim for 600 to 1500 words for `normal`, shorter for `quick`, up to about 2500 for `deep`. Cut padding. A short report with strong evidence beats a long one.
