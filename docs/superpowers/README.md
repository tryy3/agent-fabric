# Historical design records

The dated documents in `plans/` and `specs/` are implementation-time proposals and design records. They are retained for decision history and may describe completed work, superseded APIs, earlier toolchains, or intentionally deferred ideas.

For the current product contract, start with the repository [README](../../README.md), [architecture](../architecture.md), [decisions](../decisions.md), and [DESIGN](../../DESIGN.md). Do not treat a dated plan or spec as a current operational guide without verifying it against those documents and the code.
